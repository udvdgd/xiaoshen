# 小神学习库 · 从零到进阶（教学向）

> 让零基础的人按顺序学完，具备看懂系统、保护自己机器、做合法安全实验的能力。
> 讲原理、讲防御、讲学习方法；不提供可打真实目标的攻击步骤。实验只在自己虚拟机/靶机/授权环境做。

## 学习路线
```
阶段0 工具与命令行
阶段1 一门语言（先 Python，再 C/Shell/Lua）
阶段2 操作系统与网络原理
阶段3 Web 与脚本安全概念
阶段4 二进制/底层（root/刷机是什么）
阶段5 防御实践（加固/巡检/补丁）
阶段6 CTF 进阶（见 vulndb/ctf/）
```

## 阶段0 工具与命令行
Linux 常用命令（cd/ls/cat/grep/find/chmod/ps/ss）、管道与重定向、包管理器（apt/pacman/dnf/pkg）。实验环境用 VirtualBox Ubuntu 或 Termux。

## 阶段1 编程语言
- Python：变量/函数/文件/请求（本项目 run.py 即范例）
- Shell：变量/循环/条件/管道（看懂 .sh 壳）
- C：指针/数组/缓冲区（理解“溢出”为何是问题）
- Lua：语法基础（看懂手机脚本）
- 学法：每门写 3 个小工具。

## 阶段2 操作系统与网络
进程/线程、文件权限 rwx、root 用户、TCP/IP、端口、HTTP/HTTPS、DNS、代理原理（本项目 proxy.py）、SSH/RDP 远程管理与内网穿透原理（合法运维用途）。

## 阶段3 Web 与脚本安全（原理+防御）
- SQL 注入=输入被当 SQL 执行 → 参数化查询
- XSS=页面执行了别人塞的脚本 → 输出转义
- SSRF=服务器被诱导访问内网 → 地址白名单
- 文件上传/包含、反序列化：原理与最小权限
- 脚本加解密：编码/混淆/对称/非对称区别（本项目练手）

## 阶段4 底层与 root/刷机
- root=Linux 超级用户；手机默认加沙箱
- 刷机/解锁 Bootloader：原理、风险（变砖/失保修/银行 App 不可用）、合法用途（自己设备/研究）
- 提权原理分类见 vulndb/PRINCIPLE.md；不教在别人设备 root，只教理解机制和给自己打补丁。

## 阶段5 防御实践
- desktop/selfcheck.py：端口/SSH/防火墙/自动更新自检
- desktop/phone_audit.py：USB 连手机查补丁区间
- vulndb/query.py：查 CVE 影响与修复
- 加固：改默认口令、关不用端口、开自动更新、最小权限

## 阶段6 CTF
见 vulndb/ctf/README.md。

## 法律红线（贯穿始终）
只在自己设备或授权靶场/比赛动手；未授权入侵违反《网络安全法》《刑法》285/286。本库教看懂与防御，不教攻击真实目标。
