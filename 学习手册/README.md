## 蓝队 vs 红队
- 蓝队（防守）：找漏洞、打补丁、加固、监测——本项目大部分属于这侧。
- 红队（进攻演练）：在**书面授权**下模拟攻击验证防守。无授权打真实系统违法；练手只去 CTF/官方靶场（见 vulndb/ctf/）。
