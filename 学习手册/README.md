# 学习手册（从小白到大牛 · 教学向）

> 一本看完就能入门的安全学习手册。讲原理、讲路线、讲怎么选工具；
> 红队/白队都讲“在做什么、为什么、怎么防”，不提供打真实目标的攻击步骤。
> 所有动手实验只在自己虚拟机 / 官方授权靶场 / 比赛环境进行。

## 一、你将学到什么
看懂电脑/手机怎么跑；看懂 .py/.sh/.lua/.js 在做什么；懂常见漏洞为什么能被利用、怎么补；会给自己机器/手机加固；具备打 CTF、走安全岗的基础。

## 二、阶段路线
| 阶段 | 内容 | 产出 |
|---|---|---|
| 0 | 命令行+Linux | 熟练敲命令、看懂进程 |
| 1 | Python | 写 3 个小工具 |
| 2 | 网络与 OS 原理 | 懂 TCP/端口/HTTP/权限 |
| 3 | Web 与脚本安全 | 懂漏洞原理与防御 |
| 4 | 底层/二进制 | 懂 root/刷机/提权原理 |
| 5 | 防御实践 | 会加固/巡检/查补丁 |
| 6 | CTF 实战 | 见 vulndb/ctf/ |

## 三、白队（防守）
资产清点、打补丁、防火墙、查日志、应急、巡检。本仓库现成：desktop/selfcheck.py、desktop/phone_audit.py、vulndb/query.py、vulndb/PRINCIPLE.md。

## 四、红队（进攻演练）
在授权渗透测试里模拟攻击者找薄弱点。流程概念：信息收集→找入口→提权→横向→出报告（每步讲测什么、怎么防，不教真实利用）。本仓库不内置打真实目标的工具；前提永远是甲方书面授权。

## 五、漏洞与攻击原理速查
| 名字 | 原理 | 怎么防 |
|---|---|---|
| SQL 注入 | 输入被拼进 SQL 执行 | 参数化查询 |
| XSS | 页面执行外部塞入脚本 | 输出转义 |
| SSRF | 服务器被诱导访问内网 | 目标白名单 |
| 文件上传 | 传可执行文件并被执行 | 后缀校验+隔离目录 |
| 提权 LPE | 低权限拿到 root/system | 打补丁/最小权限/SELinux |
| UAF/竞争 | 释放后仍用/时序窗口被抢 | 内核补丁/内存加固 |
| 整数溢出 | 长度算错致越界写 | 边界检查 |
| 中间人 | 传输中被偷看/篡改 | HTTPS+证书校验 |
| 弱口令/爆破 | 密码简单被试出 | 强口令/限速/多因子 |

## 六、推荐工具清单
- 学习靶场：picoCTF、PortSwigger Web Academy、cryptopals、ROP Emporium、crackmes.one、CTFtime
- 防御/运维：Python、ss/netstat、ufw/firewalld、ssh、Wireshark、binwalk
- 代理/远程：本项目 desktop/proxy、ssh、RDP
- 加解密练手：本项目 run.py/encryptor（自己的文件）
- 不推荐、也不内置任何“一键打别人”的攻击工具。

## 七、编程语言
Python（先学）、Shell、C（懂指针/缓冲区）、Lua、JS。

## 八、法律红线
只在自己设备或授权环境动手；未授权入侵违反《网络安全法》《刑法》285/286。本手册教看懂与防守，不教攻击真实目标。
