# Linux/Termux 命令大全（逐个拆）
> 每个命令：作用+写法+例子，自己设备练。

## 文件目录
pwd 在哪；ls -la 详细；cd 目录/cd ..；mkdir -p a/b；rm -r 目录(小心)；cp -r；mv 重命名；find . -name "*.py"；touch。

## 看内容
cat；less；head -n 20；tail -f 日志；grep -r 关键词 目录。

## 权限
chmod +x 脚本；chmod 644；chown。

## 进程
ps aux；top/htop；kill；kill -9；nohup 程序 &。

## 网络
ping；curl URL；wget；ss -tulnp；ip addr；ip route；scp 文件 用户@IP:/路径。

## 压缩
tar -czf / tar -xzf；zip/unzip。

## 管道与重定向
|；> 覆盖；>> 追加。

## 包管理
apt install / pacman -S / dnf install。

## 系统
df -h；free -h；uname -a；date。

记不住用 `命令 --help`；删前看清路径；报错读最后一行。
