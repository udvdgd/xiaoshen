# 手机/电脑工具推荐（合法用途）

> 先从 noroot 开始；root 有风险（变砖/失保修/银行App不可用），只对自己设备操作。本目录不提供/不下载 root exploit 或破解工具。

## 一、Noroot（推荐先玩）

### Termux（安卓终端，免root）
手机上的 Linux 命令行。用法：官方 F-Droid/GitHub 安装 → `pkg update && pkg install python` → 跑自己的脚本。关电池优化防被杀。

### MT 管理器
文件管理/文本查看/解压；双栏操作，长按看属性权限。

### 电脑端
VirtualBox/VMware 装 Ubuntu 做实验；VS Code；Python3、git。

## 二、需要 root（进阶，自己设备）
root 后银行 App 可能风控、解锁会清数据失保修。Magisk 等只作为概念了解，本仓库不提供安装包，请到官方渠道并遵守法律与厂商条款。

## 三、本项目自带工具
| 工具 | 位置 | 干什么 |
|---|---|---|
| 加解密主程序 | run.py | 标准算法解密/独家混淆加密 |
| 本地代理 | desktop/proxy/ | SOCKS5+HTTP 免费转发 |
| 手机补丁巡检 | desktop/phone_audit.py | USB 连机查提权区间 |
| 本机自检 | desktop/selfcheck.py | 端口/SSH/防火墙/更新 |
| 漏洞查询 | vulndb/query.py | 查 CVE 影响与修复 |

## 下载提示
App 只从官方商店/官方 GitHub releases 下；“一键root/破解/卡密破解”一律不装。
