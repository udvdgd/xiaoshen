# 教程 2：加密是怎么回事（拿自己的文件练）

对称加密(AES)同钥匙加解密；编码/混淆(base64/异或)只是让人看懂变难，不是真加密。真安全用 AES-256-GCM。

```bash
python3 -c "
s='小神测试'.encode(); k=b'1234'
e=bytes(b^k[i%len(k)] for i,b in enumerate(s))
print('混淆后:',e.hex())
d=bytes(b^k[i%len(k)] for i,b in enumerate(e))
print('还原:',d.decode())"
```
异或本质：加解密同一个动作，改 k 就是换钥匙。
