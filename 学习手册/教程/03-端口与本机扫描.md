# 教程 3：端口是怎么回事（只扫自己电脑）

端口=服务的门：80网页 443 22SSH 1080代理。

```bash
ss -tulnp
```
只看自己机器，别扫别人公网 IP。

```bash
python3 -c "
import socket
for p in (22,80,443,1080,1081):
    s=socket.socket(); s.settimeout(0.3)
    r=s.connect_ex(('127.0.0.1',p)); s.close()
    print(p,'open' if r==0 else 'closed')"
```
只连本机回环。
