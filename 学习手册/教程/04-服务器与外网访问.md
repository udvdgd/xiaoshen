# 服务器搭建与外网访问（自学教程）
> 只针对自己的服务器/设备。

## 基础
租 VPS 拿 IP；`ssh 用户@IP` 连；Ubuntu 用 apt。

## 跑服务
```bash
sudo apt update && sudo apt install -y python3
python3 -m http.server 8000
```
云安全组放行 8000。

## 安全
SSH 用密钥、改端口；防火墙只放必要口；及时升级；别用弱密码。

## 没公网IP怎么让外网访问
1. 自有 VPS 反向隧道：家机执行 `ssh -R 8000:localhost:8000 用户@VPS_IP`；或 frp/nginx 反代。
2. 合法内网穿透服务（开发调试用）。
3. 有公网IP就路由器端口映射。

## 坑
安全组没放行；服务只绑127.0.0.1要绑0.0.0.0；运营商封80/443换高端口；公网服务要加认证。
