# 学习路线图（小白 → 大佬）

## 阶段0 会用电脑和命令行（1-2周）
装 Ubuntu 虚拟机或手机 Termux；学会 cd/ls/cat/grep/find/chmod/ps/ss/管道/重定向。

## 阶段1 会写一点脚本（2-4周）
Python（变量/函数/文件/HTTP）、Shell（看懂 .sh）；每门写 3 个小工具。

## 阶段2 懂系统和网络（1个月）
进程/端口/权限、TCP/IP、HTTP/HTTPS、DNS、代理、SSH。

## 阶段3 安全概念（1个月）
漏洞原理+防御：溢出=边界检查；注入=参数化/转义；越权=服务端鉴权；提权=补丁/SELinux/最小权限。

## 阶段4 动手做防御
跑 desktop/selfcheck.py、desktop/phone_audit.py、vulndb/query.py，把自己设备加固到合格。

## 阶段5 CTF 进阶
见 vulndb/ctf/README.md，picoCTF → PortSwigger → cryptopals。

## 阶段6 红队概念（只学原理）
入侵分几步：踩点→入口→提权→横向→留痕；每步对应什么防守。无书面授权一步都不能对真实系统做。
